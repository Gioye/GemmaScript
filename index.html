How to use GemmaScript

  • Describe the code you want in plain English
  • Specify the programming language or let the AI detect it
  • Gemma 3 will generate code inside <gemmascript-code type="language"> tags
  • Only the code INSIDE the tags will be extracted and displayed
  • HTML code (type="html") will be rendered live in the preview pane
  • Each request is independent (memoryless AI)
